Heute versenden wir 26.2 Snapshot 8! OpenGL ist jetzt der Standard, während Vulkan sich in experimentelles Gebiet bewegt. Sie finden auch Updates zu der Schwefelhöhle und Schwefelwürfel, zusammen mit Betten, die jetzt ein bisschen mehr als zuvor sind!

Frohes Verspotten!

# Neue Features

## Sulfur Caves bio

-   Wenn der Oberfläche ausgesetzt, wird das Biome mit allen Merkmalen der unterirdischen Sulfur Caves Biome erzeugen

## Schwefel Cube mob

-   Schwefelwürfel, die einen Block im Inneren enthalten, sind nun immun gegen Schäden von Magma-Blöcken, sowie von anderen Schwefelwürfeln, die einen Magma-Block enthalten

# Änderungen

-   Das Spiel wird jetzt OpenGL Grafik API standardmäßig verwenden
-   Die Betten sind nun etwas mehr Bouncy zum Spiel Bedrock

## Geändert "Graphics API" Videoeinstellung

-   "Vulkan" ist jetzt als "Experimental" gekennzeichnet
    -   Sie können es immer noch verwenden, wenn Sie wollen, es funktioniert gut an den häufigsten Systemen, aber kann die Leistung reduzieren oder Instabilität auf einigen anderen Systemen verursachen
-   "Standard" Option wird jetzt OpenGL hinter den Kulissen verwenden
-   Die Einstellung wird auf "Standard" für alle Spieler zurückgesetzt

## UI Sprites

-   Zusätzlich `friends/background_dark` — eine dunklere Variante der `friends/background` Panel-Sprite, als Hintergrund für Bestätigung Dialoge in den Freunden UI verwendet

# Technische Veränderungen

-   Die Data Pack Version ist jetzt 106.0

## Schadensarten

-   Neu hinzugefügt `minecraft:sulfur_cube_hot` Schadensersatz

# Datenpaket Version 106.0

## Befehle

### Publizieren

-   Die `publish` Befehl nimmt jetzt einen zusätzlichen boolean, wie es erste Argument, um festzulegen, ob der Server für Online-Multiplayer oder nur lokale Multiplayer geöffnet werden sollte
    -   Standard: true (online multiplayer)

### Unpublish

-   Zusätzlich `unpublish` Befehl, der Ihren integrierten Server freigibt, wenn ein vorhanden ist
