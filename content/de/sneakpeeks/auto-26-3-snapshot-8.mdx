Dieser Mittwoch, ein heißer neuer Snapshot kommt ins Reich! Das ist richtig, in 26.3 Snapshot 8, Realm-Besitzer können jetzt erstellen und verwalten Invite Codes, so dass es einfacher als je zuvor, um den Spaß zu verbinden.

Neben diesen Ergänzungen haben wir weitere Verbesserungen auf dem World Options-Bildschirm gemacht und mehrere Gameplay-Fixes und technische Updates enthalten.

Glücklicher Bergbau!

# Neue Features

## Explorer Karten

-   Umbenennte die folgenden Karten:
    -   Karte der alten Stadt
    -   Karte der Bergwerkswelle
    -   Verlassene Camp Map

## Reiche

-   Realm-Besitzer können jetzt Invite Codes erstellen und verwalten
    -   Jeder Bereich kann bis zu fünf Invite Codes haben
    -   Einladungscodes können aktiv / inaktiv und gelöscht konfiguriert werden
    -   Der Ablauf eines Einladungscodes kann auch konfiguriert werden
-   Spieler können sich nun leicht an einen Realm anschließen, indem sie einen Invite Code in einem neuen "Join Realm"-Bildschirm eingeben

# Änderungen

-   Kissen werden jetzt nur zerstört, wenn vollständig von Blöcken abgedeckt, die Suffocation verursachen
-   Neue Villager Trades, entsperrt von einem Villager, der ihren Beruf aufrechterhält, werden jetzt auch aktualisieren, wenn der Spieler im Prozess des Handels mit ihnen ist

## UI

### Weltoptionen

-   Einige weitere Verbesserungen wurden auf dem World Options-Bildschirm vorgenommen, der nun aus dem Pausenmenü zugänglich ist.
    -   Die Schaltfläche "Spielmodus" wurde in "Standard-Spielmodus" umbenannt
    -   Der Abschnitt "Allgemeine" hat eine neue Ergänzung:
        -   Persönlicher Spielmodus: Ihr aktiver Spielmodus in der aktuellen Welt (entspricht der `/gamemode` Befehl oder F3+F4)
    -   Der Abschnitt "Multiplayer" hat eine neue Ergänzung:
        -   Force Game Mode: kontrolliert, ob andere Spieler Spielmodus gezwungen ist, den Standard-Spielmodus der Welt anzupassen oder nicht

# Technische Veränderungen

-   Die Data Pack Version ist jetzt 116.0
-   Die Resource Pack Version ist jetzt 96.0

# Datenpaket Version 116.0

## Weltgeneration

### Eigenschaften

-   Entfernen von Funktionstypen:
    -   `minecraft:desert_well`

#### Geändert `minecraft:template`

-   Zusätzliches Feld `processors`: Namespaced ID oder Inline Definition einer Strukturprozessorliste für die Vorlage

### Ortung Modifiers

#### Zusätzlich `minecraft:randomly_selected`

Randoly wählt einen Placement Modifier aus einer Liste und delegiert Platzierung darauf.

Format:

-   `placements`: Nicht leere Liste der Placement Modifier zur Auswahl

### Block Predicates

#### Zusätzlich `minecraft:volume_match`

Prüft, dass jeder Block in einem Volumen einem bestimmten Block Predicate entspricht.

Format:

-   `min`: Liste von 3 Ganzzahlen im Bereich `-16` bis `16` Vorgeben der unteren Ecke des Volumens als Versatz von der Prüfposition
-   `max`: Liste von 3 Ganzzahlen im Bereich `-16` bis `16` Angabe der oberen Ecke des Volumens als Versatz von der Prüfposition
-   `match`: Block Prädikat für jede Position zu testen

# Resource Pack Version 96

## Shaders & Post-Prozess-Effekte

### Entfernte Core Shaders

-   `core/text_background.fsh` und `core/text_background.vsh` wurden entfernt und Texthintergrund in Text-Anzeige-Entities wird nun mit den Text-Scheinern wiedergegeben

### Auftragsunabhängige Transparenz (OIT)-bezogene Shader-Änderungen

-   `OIT_FORCE_ZERO_DEPTH` Shader-Definition wurde entfernt, da der durchsichtige Text, für den er verwendet wurde, jetzt in einem separaten Pass außerhalb von OIT dargestellt wird
