Heute versenden wir die erste Pre-Release für Java Version 26.1, die Tiny Takeover Spiel Drop! Ab jetzt sollten Sie meist sehen, wie Fehler behoben werden. Darüber hinaus folgen Pre-Releases nicht der regelmäßigen Snapshot-Cadence der Freigabe am Dienstag, so halten Sie Ihre Augen geschält für die nächste Pre-Release.

# Änderungen

-   Das Hintergrundpanorama Main Menu aktualisiert

# Technische Veränderungen

-   Die Data Pack Version ist jetzt 101
-   Die Resource Pack Version ist jetzt 84
-   Änderungen an der `minecraft:nbt` Textkomponente Format
-   Änderungen an der `minecraft:selector`, `minecraft:nbt` und `minecraft:object` Textkomponentenformate

# Datenpaket Version 101

-   Der Reportgenerator "Default Components" gibt keine Dateien mehr für Einträge ohne Komponenten aus

## Befehle

### Änderungen an `time`

Syntax:

-   `time [of <clock>] rate <rate>` - sets the rate multiplier at which the clock should advance
    -   Note: this only changes the rate at which the World Clock and any Timelines dependent on it advance their internal timers
        -   For example, in the case of the `minecraft:overworld` clock, the day/night cycle will pass quicker with a larger value, but actual game simulation will not speed up (as would happen with `/tick rate`)
    -   A `rate` of `1` corresponds to normal speed
    -   `rate` is a float between `0` (exclusive) and `1000` (inclusive)

## Data Components

### Modified `minecraft:provides_banner_patterns`

-   The component now also accepts an ID or a list of IDs in addition to a tag

### Modified `minecraft:blocks_attacks`

-   The field `bypassed_by` now also accepts an ID or a list of IDs in addition to a tag

### Modified `minecraft:damage_resistant`

-   The field `types` now also accepts an ID or a list of IDs in addition to a tag

## Loot Functions

### Changed `minecraft:set_instrument`

-   The `options` field now also accepts an ID and a list of IDs in addition to a tag

## Predicates

### Added `minecraft:environment_attribute_check` Loot Predicate

Exactly matches the value of an Environment Attribute at a given position. Note: this predicate requires a context with an `origin` position set as long as the Environment Attribute can vary positionally.

Format: object with fields:

-   `attribute` - Environment Attribute ID to test
-   `value` - Exact value of the Environment Attribute to match
-   e.g. `{condition: 'environment_attribute_check', attribute: 'gameplay/piglins_zombify', value: true}`

## Number Providers

### Added `minecraft:environment_attribute`

Fetches and provides the value of an Environment Attribute (that can be represented as a number). Note: this provider requires a context with an `origin` position set as long as the Environment Attribute can vary positionally.

Format: object with fields:

-   `attribute` - Environment Attribute ID to fetch
-   e.g. `{type: 'environment_attribute', attribute: 'gameplay/sky_light_level'}`

## World Generation

### Flower Features

-   Eigenschaften, die von der Knochen-Meal ausgestoßen werden, sind nicht mehr auf die `flower` Merkmalstyp und stattdessen von der `#can_spawn_from_bone_meal` Configured Feature Tag
-   Die `flower`, `flower_no_bonemeal`, und `random_patch` Funktionstypen wurden entfernt
    -   Stattdessen können Patches als Folge von `count` und `random_offset` Platzierungsmodifikatoren

### Int Provider

#### Zusätzlich `trapezoid` Int Provider

Wählen Sie einen Zufallswert mit einer Trapezverteilung, ähnlich der `trapezoid` Float Provider.

Format: Objekt mit Feldern:

-   `min`: ganze Zahl, der Mindestwert zu erzeugen
-   `max`: ganze Zahl, der maximale Wert zu erzeugen
-   `plateau`: ganze Zahl, die Breite des "plateau" der Verteilung, in der alle Werte gleichwahrscheinlich auftreten
    -   Wert `0` entspricht einer Dreiecksverteilung
    -   Wert `max-min` entspricht einer gleichmäßigen Verteilung

## Schlagwörter

### Konfigurierte Feature Tags

-   Zusätzlich `#can_spawn_from_bone_meal` - Merkmale, die, wenn in einem Biom hinzugefügt, kann bei der Verwendung von Bone Meal in diesem Biom laichen

## Textkomponenten

### \`minecraft:Objekt

-   Hinzugefügt ein neues optionales Feld benannt `fallback` die eine Textkomponente enthält, die verwendet werden soll, wenn die Objektkomponente selbst nicht angezeigt werden kann (z.B. beim Drucken von Nachrichten in Serverprotokollen oder während der Erzählung)
-   Sachgegenstände `player` (Spielköpfe) kann nicht mehr in Serverstatus-Nachrichten (MotD) verwendet werden
    -   Alle Bestandteile dieser Art werden durch einen Rückfalltext ersetzt.

# Ressourcenpaket Version 84

-   Aktualisierte Texturen für Pup, um Probleme mit überlappenden Texturen zu beheben

## Artikel Modelle

### `minecraft:end_cube` Typ des Modells

-   Neuer Sondermodelltyp, der einen Würfel mit den gleichen Textureffekten wie das End Portal und die End Gateway Blöcke macht
-   Felder:
    -   `effect` - Textureffekt anzuwenden, einer von: `portal`, `gateway`

## Block State Rendering

-   End Gateway und End Portal sollten nun gleich aussehen, wenn sie auf einem Block-Display wie sie aussehen, wenn in der Welt platziert

## Shaders & Post-Prozess-Effekte

-   Die `core/rendertype_translucent_moving_block` Schattierungen wurden zugunsten von `core/block`
