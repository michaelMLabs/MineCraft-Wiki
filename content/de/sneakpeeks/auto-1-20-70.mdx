# Vanilla Parity:

## Mobs

-   Wölfe können nun dem gleichen Schaden wie in Java Edition standhalten
    -   Anstatt alle Schäden an gezähmten Wölfen durch andere Wesen als Spieler oder Pfeile, wie derzeit in Java Edition getan, die maximale Gesundheit der gezähten Wölfe wurde von 20 auf 40 erhöht
    -   Vorbestehende gezähmte Wölfe müssen gefüttert werden, um die neue maximale Gesundheit zu erreichen
    -   Um sicherzustellen, dass die Heilungsrate konsistent bleibt, wurde die Gesundheit, die durch Fütterung von Wölfen wiederhergestellt wurde, verdoppelt
    -   Java Edition wird angepasst an die neue Bedrock Edition Implementierung

# Experimentelle Eigenschaften:

## Windkraftanlage

-   Werden Sie die Breeze! Mit einer Windladung wird ein Wind Charge Projektil abfeuern ähnlich wie die Breeze
-   Eine Windladung, die von einem Spieler gefeuert wird, gewährt 10% mehr Rückschläge als ein Breeze's
-   Genau wie das Projektil, das von der Breeze gefeuert wurde, machen Windladungen, die vom Spieler gefeuert wurden, auch Schaden, wenn sie direkt ein Unternehmen treffen
-   Die Breeze fällt zwischen 4-6 Wind Chargen, wenn getötet
-   Windladungen haben eine maximale Stapelgröße von 64
-   Es gibt eine halbe zweite Abkühlung nach jedem Gebrauch
-   Windladungen können von einem Spender gefeuert werden
-   Spieler, die sich mit einer Windladung starten, sammeln nur Schaden unter der y-Ebene, wo sie kollidierten mit dem Wind Burst

## Bogged

-   Eine neue Variante von Skeletons, die giftige Pfeile schießen
    -   Sie sind schneller, um mit 16 Gesundheit anstatt 20 Gesundheit zu nehmen
    -   Sie greifen in einem langsameren Intervall von 3,5 Sekunden statt 2 Sekunden an.
-   Hat eine Chance, Arrows of Poison zu fallen, wenn von Spielern getötet
-   Diese Mossy und Pilz bedeckt Skeletons spawn natürlich in Swamps und Mangrove Swamps
    -   Kann auch von Trial Spawners in einigen Trial Chambers gefunden werden

## Vault

-   Ein Block, der gesperrten Schatz und Beute hält - finden Sie den richtigen Schlüssel, um seine Belohnungen auszuwerfen
    -   Gefunden in Trial Chambers, mit den wertvollsten Looten der Strukturen
    -   Gewölbe in Trial Chambers erfordern einen Trial Key zu entsperren
-   Kann durch eine unbegrenzte Anzahl von Spielern entsperrt werden
    -   Nachdem ein Spieler einen Vault entsperrt hat, können sie diesen Vault nicht wieder entsperren
    -   Wenn ein Spieler nicht entsperrt, dass Vault zuvor, ein oranger Strom von Partikeln wird von dem Spieler zum Vault fließen, wenn in der Nähe
-   Hat ein Schlüsselloch, das geöffnet oder geschlossen wird, abhängig von den Spielern in der Nähe
    -   Wenn ein Spieler in der Nähe nicht entsperrt, dass Vault, das Schlüsselloch wird geöffnet
    -   Wenn alle nahe gelegenen Spieler dieses Vault entsperrt haben, wird das Schlüsselloch geschlossen
-   Innerhalb seines Käfigs wird es durchfahren und anzeigen Gegenstände, die aus seinem Tisch ausgeworfen werden können
-   Die Belohnungen, die sie ausstossen, werden jedes Mal, wenn sie entriegelt ist, von seinem Tisch randomisiert.
-   Tresore verwenden derzeit den gleichen Löot-Tisch, dass Belohnungskästen vorher in den Trial Chambers verwendet
    -   Dieser Tisch ist vorübergehend und wird vollständig überarbeitet, da die Entwicklung weitergeht
-   Kann nicht in Survival-Modus hergestellt oder erhalten werden und fällt nichts, wenn abgebaut
-   Explosionsgeschützt und nicht bewegt werden

## Wolf

-   Die Kragen der gezähten Wölfe wurden vergrößert, so dass sie nicht nur von vorne, sondern auch von anderen Winkeln sichtbar sind.

# Korrekturen und Änderungen:

## Leistung / Stabilität

-   Ein Fehler behoben, der dazu führen könnte, dass der Ladebildschirm für einige Zeit rund 40% feststeckt (MCPE-175550)
-   Es wurde ein Problem behoben, bei dem das Spiel während der Anzeige der "Loading-Ressource-Packs" Modal weichmachen konnte
-   Behoben ein Problem, das das Spiel beim Wechsel von Sprachen auf einigen Plattformen einfrieren könnte

## Gameplay

-   Upward Spieler-Bewegung wird nun die Fallstrecke zurückgesetzt, so dass Riptide Tridents einen Fall brechen (MCPE-126454)
-   Spieler können jetzt Blöcke über Wasser (MCPE-163165)
-   Festes Himmellicht wird nicht richtig aktualisiert, wenn große Luftspalte zwischen der Decke und dem Boden vorhanden waren
-   Behoben eines Bugs, der manchmal verhindern könnte, dass der Stronghold Portalraum erzeugt wird (MCPE-19426)
-   Behobene Spieler entsperren nicht “The Beginning” Trophäe auf PlayStation, um einen Wither zu besiegen, auch wenn sie nahe genug zum Wither waren

## Mobs

-   Wenn gefüttert, Baby mobs emittieren jetzt sowohl Klang als auch Partikel
-   Alle Geräusche, die Phantoms ausgestrahlt werden, sind jetzt hörbar, auch wenn der Spieler wegschaut
-   Alle Klänge von Wardens sind jetzt hörbar, auch wenn der Spieler weggeblickt ist
