Heute ist es Zeit für 26.2 Pre-Release 5, mit einem Wechsel zu Hardcore-Modus Einstellungen zusammen mit anderen Fixes! Wie bei Minecraft Live angekündigt, wird der Tropfen am 16. Juni veröffentlicht!

Happy (vorsichtig) Hardcore Bergbau!

# Änderungen

-   Die Spieleinstellung für Graphics API ändert sich nun, wenn ein Crash während des Starts erkannt wird
-   Der Klang für den Fall, dass der Schwefelwürfel eines Bouncy-Archels trifft, spielt jetzt den richtigen Klang
-   Als Host einer Welt ändert sich der Spielmodus mit F3 + F4 oder mit Befehlen ändert nun den Standard-Spielmodus der Welt
-   Die Buttons "Game Mode" und "Allow Commands" sind in Hardcore-Modus-Welten nicht mehr verfügbar

## Startup und Fallback Verhalten für Graphics API

-   Wenn das Spiel beim Start mit "Prefer Vulkan" abstürzt, wird die Einstellung automatisch in "Standard" geändert
-   Wenn auf "Default" gesetzt, wird das Spiel immer noch versuchen, Systeminformationen über Vulkan beim Start zu sammeln
-   Wenn das Spiel beim Start mit "Default" abstürzt, wird die Einstellung automatisch in "Prefer OpenGL" geändert
    -   Mit "Prefer OpenGL"-Set wird keine Interaktion mit Vulkan gemacht, falls es Abstürzen verursacht
