Früher haben wir heute in den Schifffahrtsraum gewirkt, um Ihnen den vierten Snapshot von 26.1, mit einer Reitserie von Spiel Drop Cuteness. Mit der Veröffentlichung dieser Woche bekommen Babyhalterungen ein bezauberndes Makeover! Esel. Mules. Jede einzelne Pferdevariante. Alle diese winzigen Cuties galoppieren sich in die Überwelt, die schiller und niedlich aussieht!

Glücklicher Bergbau!

# Neue Features

-   Neue Baby-Sounds für Pferd hinzugefügt

# Änderungen

-   Überarbeitet die Visualisierungen von mehr Baby-Mobs
-   Baby Hühnerflügel Textur wurde aktualisiert/fixiert

## Baby Mobs

-   Aktualisiert die Modelle und Texturen der folgenden Babymobs:
    -   Pferde
        -   Erhöht die Begrenzungsbox von Babypferden, um das neue Modell besser zu passen
    -   Esel
    -   Mulde
    -   Zombie Pferd
        -   Erhöht die Begrenzungsbox des Babys Zombie Horses, um besser fit das neue Modell
        -   Kann nur im Creative-Modus oder mithilfe von Befehlen laichiert werden
    -   Skelettpferd
        -   Erhöht die gebundene Box des Babys Skeleton Horses, um besser fit das neue Modell
        -   Kann nur im Creative-Modus oder mithilfe von Befehlen laichiert werden

# Technische Veränderungen

-   Die Data Pack Version ist jetzt 97.1
-   Die Resource Pack Version ist jetzt 78.1

# Datenpaket Version 97.1

-   Villager und Piglin Inventarslots können jetzt nur mit Hilfe von `mob.inventory.*`. `villager.*` und `piglin.*` wurde entfernt

## Weltuhren

-   Zusätzlich `minecraft:the_end` Welttakt zur Enddimension
    -   Es steuert jetzt den Himmel blinkt im Ende

## Schlagwörter

### Block Tags

-   Hinzugefügt die folgenden Tags, die bestimmen, welche Blöcke eine Kategorie der Vegetation kann platziert werden und überleben
