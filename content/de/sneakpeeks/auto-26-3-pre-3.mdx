Der Weg zur Freilassung geht weiter mit der Vorentlassung 3! Heute stapeln wir noch eine Reihe von Bugfixes, da wir uns auf eine vollständige Veröffentlichung von 26.3. vorbereiten.

Happy Mining!

# Technische Veränderungen

-   Die Data Pack Version ist jetzt 121.0

## Anzahl Provider

### Geändert `minecraft:mod` Float Provider Typ

-   Jetzt verwendet Standardmodul anstelle von Bodenmodul, passend zur Int-Variante

### Geändert `minecraft:pow` Float Provider Typ

-   Das Anheben von 0 auf die Leistung von 0 führt nun zu einer Fehler- und Stoppberechnung, die der Int-Variante entspricht
