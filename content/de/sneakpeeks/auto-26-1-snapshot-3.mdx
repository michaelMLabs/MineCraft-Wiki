## Weltuhren

Weltuhren enthalten eine interne Zeit, die jede Zecke erhöht. Sie können in Datenpaketen unter der `world_clock` Registrierung (d.h. gefunden unter `data//world_clock/.json`)

-   Weltuhren können gepflastert oder wieder aufgenommen werden, und die Uhrzeit kann aus dem `time` Befehl
-   Format: Objekt ohne Felder

## Zeiträume

-   Zusätzlich `clock` Feld: eine Weltuhr-ID, gibt an, an welche Weltuhr die Zeitlinie gebunden ist
    -   Dieses Feld ist erforderlich, aber, um das vorherige Verhalten der `minecraft:overworld` Takt kann verwendet werden
-   Optional hinzugefügt `time_markers` Feld, eine optionale Karte zwischen namespaced Time Marker IDs und entweder einem Int oder einem Time Marker Objekt,
    -   Format:
        -   Nicht-negative Int, die Tick, dass die Zeitmarker markiert
        -   Oder Objekt mit Feldern:
            -   `ticks`: zwischen `0` und `period_ticks`, die Tick, dass der Zeitmarker markiert
            -   `show_in_commands`: optional boolean, gibt an, ob der Time Marker in Befehlsvorschlägen angezeigt wird
                -   Standard: `false`

### Zeitzeichen

Time Markers zugewiesen einen bestimmten Namen zu einem bestimmten (optional wiederholenden) Zeitpunkt für eine bestimmte Weltuhr. Time Markers ersetzen die zuvor vorgegebenen Namen, die von `/time set`z.B. `day` oder `night`.

Zeitmarker werden im Kontext einer bestimmten Weltuhr existieren. Dies bedeutet, dass, obwohl die verschiedenen Zeitmarker durch verschiedene Zeitlinien definiert sind, nur ein Zeitmarker mit einer bestimmten ID für eine bestimmte Weltuhr existieren kann. Es bedeutet auch, dass zwei Weltuhren einen Time Marker mit dem gleichen Namen haben können.

### Eingebaute Verwendungen von Time Markers

Einige Zeitmarker werden verwendet, um Vanilla-Spielverhalten zu fahren. In der Regel sind sie so konfiguriert, dass sie nicht in `/time` Befehle.

-   `minecraft:wake_up_from_sleep` - die Zeit, um die Standarduhr der Dimension voranzutreiben, wenn Spieler in dieser Dimension nach dem Schlafen aufwachen
-   `minecraft:roll_village_siege` - die Zeit der Standard-Uhr der Dimension, bei der die zufällige Chance für eine Zombie-Dorf-Belagerung auftreten sollte ausgewertet werden

## Befehle

### Änderungen an `swing`

-   Beide Argumente können jetzt weggelassen werden und werden auf folgende Standardeinstellungen zurückfallen:
    -   Der Entity-Selektor wird `@s` wenn weggelassen
    -   Welche Hand zum Schwingen wird `mainhand` wenn weggelassen

### Änderungen an `time`

-   Die `time` Befehl basiert jetzt auf World Clocks
    -   Optional kann ein Takt als Eingabe für den Zeitbefehl mit `time of <clock> ...`
    -   If the clock is not specified (`/time ...` as before), the default clock for the dimension is used
-   The return value (e.g. from `/execute store`) from the `set` and `add` subcommands is now the total elapsed ticks of the clock instead of the current time of day

Syntax:

-   `time [of <clock>] set <time>` - sets the total elapsed ticks of the clock
-   `time [of <clock>] set <timemarker>` - advances the clock forward to the next occurrence of the time marker
    -   For the `minecraft:overworld` clock, the available time markers are: `day`, `noon`, `night`, and `midnight`
-   `time [of <clock>] add <time>` - adds ticks to the clock, can be a negative or a positive number
-   `time [of <clock>] pause` - pauses the clock
-   `time [of <clock>] resume` - resumes the clock
-   `time [of <clock>] query <timeline>` - displays and returns the current number of ticks within the timeline's period
-   `time [of <clock>] query <timeline> repetitions` - displays and returns the number of times the timeline's period has repeated
-   `time [of <clock>] query time` - displays and returns the total elapsed ticks of the clock
-   `time query gametime` - as before, the total elapsed ticks within the world (unaffected by changes made to clocks using `/time`)
