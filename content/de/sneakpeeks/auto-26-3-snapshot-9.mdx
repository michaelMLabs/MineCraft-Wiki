Sieht so aus, als könnte dieser Snapshot bis Dienstag nicht warten! Einen Tag früh zu kommen, bringt es neue Anpassungsmöglichkeiten für Realms. Eigentümer können nun die Renderdistanz bis zu 25 Stück erhöhen und den Render- und Simulationsabstand separat konfigurieren, um die Balance zu finden, die für ihre Welt am besten funktioniert.

Abgesehen von diesen Änderungen haben wir auch viele technische Verbesserungen und Bugfixes enthalten.

Glücklicher Bergbau!

# Neue Features

## Reiche

-   Hinzufügen von Render-Distanz- und Simulations-Distanzschiebern zu Realm-Konfigurationseinstellungen

## Kleine Tweaks zu Blöcken, Gegenständen und Einrichtungen

-   Endermen werden jetzt Schaden von Geschossen nehmen, wenn sie etwas reiten
-   Endermen und Shulkers teleportieren nicht mehr auf Bedrock

## UI

-   Auf macOS, fügte eine Option "Right Click Emulation" in Controls-Einstellungen hinzu, die Control + Linksklick als Rechtsklick behandelt
    -   Standardmäßig ausschalten

# Technische Veränderungen

-   Die Data Pack Version ist jetzt 117.0

## Anzahl Provider

### Geändert `minecraft:sum`

-   Die `summands` Feld wurde umbenannt `operands` und akzeptiert nun einen Inline-Wert, eine einzelne Namespaced-ID, eine Liste von Namenspaced-IDs, eine Liste von Inline-Werten oder eine Hash-Prefixed-Tag-ID einer `minecraft:number_provider` Typ
-   Jetzt erfordert mindestens einen Operanden
-   Bei der Anwendung im Integer-Modus wird der Integer-Modus auch für Zwischenschritte verwendet.

### Zusätzlich `minecraft:product`

-   Felder:
    -   `operands` - Eine Liste von Nummern als Inline-Wert, eine einzelne Namespaced-ID, eine Liste von Namenspaced-IDs, eine Liste von Inline-Werten oder eine Hash-Prefixed-Tag-ID einer `minecraft:number_provider` Typ
-   Gibt das Produkt der Operanden zurück, multipliziert sie alle zusammen
-   Erfordert mindestens einen Operanden

### Zusätzlich `minecraft:minimum`

-   Felder:
    -   `operands` - Eine Liste von Nummern als Inline-Wert, eine einzelne Namespaced-ID, eine Liste von Namenspaced-IDs, eine Liste von Inline-Werten oder eine Hash-Prefixed-Tag-ID einer `minecraft:number_provider` Typ
-   Gibt den minmimum Wert der Operanden zurück
-   Erfordert mindestens einen Operanden

### Zusätzlich `minecraft:maximum`

-   Felder:
    -   `operands` - Eine Liste von Nummern als Inline-Wert, eine einzelne Namespaced-ID, eine Liste von Namenspaced-IDs, eine Liste von Inline-Werten oder eine Hash-Prefixed-Tag-ID einer `minecraft:number_provider` Typ
-   Gibt den minmimum Wert der Operanden zurück
-   Erfordert mindestens einen Operanden

### Zusätzlich `minecraft:average`

-   Felder:
    -   `operands` - Eine Liste von Nummern als Inline-Wert, eine einzelne Namespaced-ID, eine Liste von Namenspaced-IDs, eine Liste von Inline-Werten oder eine Hash-Prefixed-Tag-ID einer `minecraft:number_provider` Typ

-   Gibt den Durchschnittswert der Operanden zurück
-   Erfordert mindestens einen Operanden
